Selected work

Three things I built end to end, and what each one taught me.

OCR-KYC pipeline

At Scalean Technologies

Checking ID documents by hand is slow, and people make typing mistakes. So I built a pipeline that takes a photo of an ID and pulls out the name, date of birth and address as clean, structured data. It runs PaddleOCR on a GPU behind a FastAPI backend. A TypeScript frontend shows the image, the fields it found, and how confident the model is about each one. Sign-in uses one-time passwords and blocks brute-force attempts.

Before writing the pipeline, I tested three OCR engines (Tesseract, EasyOCR and PaddleOCR) on the same documents. That taught me to choose tools by measuring them, not by guessing. The biggest speed-up was simple: load the model into memory once instead of on every request. That brought each document down to 1–2 seconds. I also learned that OCR gives you raw text, not answers. A lot of the work was grouping lines by where they sit on the page and using regex to find each field.

After Plan

At Scalean Technologies

After Plan is an onboarding app I built from scratch. New users go through a five-step wizard in React, backed by FastAPI and PostgreSQL. I first built it as one layered app, where routes call services, services call repositories, and repositories talk to the database. Later I split it into four services (Auth, Party, Account and Submission) behind an API gateway, with Consul so the services can find each other.

This project taught me why you would split an app into services, and what that costs. With four services instead of one, I had to think about how services discover each other, how the gateway checks every request, and the difference between proving who someone is (authentication) and deciding what they are allowed to do (authorization). I came out of it understanding JWT, rate limiting and API versioning properly, not just copying them from a tutorial.

  • React
  • FastAPI
  • SQLAlchemy
  • PostgreSQL
  • JWT
  • Microservices
  • Consul

Instagram DM agent

Personal project

Replying to every Instagram DM takes time, so I built an n8n agent that answers them for me in my own short, casual texting style. It has handled 1,000+ DMs.

Getting the bot to reply was the easy part. The hard part was teaching it when not to. A bot that answers everything will eventually say the wrong thing, so when a message is tough, sensitive or needs me personally, the agent does not guess. It sends a Pushover alert to my phone and I reply on Instagram myself. Building it showed me that a good AI product is mostly about deciding where the human steps in.
